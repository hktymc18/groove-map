NAVIGATOR

個人情報保護方針

第1版（2026-10）／ 【施行日】施行
PROMOTE（以下「当団体」という。）は、当団体が提供する NAVIGATOR（旧名称 GROOVE MAP）、ATTACK LIST 及び GOAL SETTING（以下総称して「本サービス」という。）における個人情報の取扱いについて、個人情報の保護に関する法律（平成15年法律第57号。以下「個人情報保護法」という。）その他の関係法令及び個人情報保護委員会が定めるガイドラインを遵守し、以下のとおり個人情報保護方針（以下「本方針」という。）を定める。本サービスを利用する者（以下「ユーザー」という。）は、本方針の全条項を熟読し、その内容に同意した上で本サービスを利用するものとする。

第1条（定義）

本方針において使用する用語の定義は、次の各号に定めるとおりとする。

  1. 「個人情報」とは、個人情報保護法第2条第1項に定める個人情報をいう。
  2. 「個人データ」及び「保有個人データ」とは、それぞれ個人情報保護法第16条第3項及び第4項に定めるものをいう。
  3. 「登録対象者」とは、ユーザーが本サービスに情報を登録する、ユーザー以外の個人（チームメンバー、連絡先として登録する者その他の第三者をいう。）をいう。
  4. 「共有機能」とは、ユーザーが明示的に指定した他のユーザーに対し、自己の登録情報の全部又は一部の閲覧又は編集を許可する本サービスの機能をいう。

第2条（適用範囲）

本方針は、本サービスの提供に関して当団体が取得し、又は取り扱う全ての個人情報に適用される。本サービスからリンクされた外部のウェブサイト及びサービスにおける個人情報の取扱いについては、当該ウェブサイト等の運営者の定めるところによるものとし、当団体は一切の責任を負わない。

第3条（取得する個人情報及び取得の方法）

当団体は、適法かつ公正な手段により、次の各号に掲げる個人情報を取得する。

  1. ユーザーがアカウント登録時に入力する情報（氏名、屋号、所属ユニオン、活動地域、UPルビー、UPBD、電子メールアドレス及びパスワード認証に係る情報）
  2. アカウントの管理に関する情報（承認状態、役割、本方針及び利用規約への同意の有無、同意した版及び同意の日時）
  3. ユーザーが本サービスに入力し、又は登録する情報（組織図に登録する登録対象者の氏名、タイトル、活動状況、地域、性別、生年月日、研修の記録その他の情報、予定、タスク、目標、収入目標、チェックリスト、ATTACK LIST に登録する連絡先の情報等）
  4. 本サービスの利用に伴い記録される情報（最終ログイン日時、プッシュ通知の送信に用いる端末識別子、Googleカレンダー連携の設定情報、受付システム（BASE CHECK-IN）との連携により取り込まれる研修及び会合への出欠の記録、ユーザーが送信した不具合報告及び要望の内容）

第4条（利用目的）

当団体は、取得した個人情報を、次の各号に掲げる目的の達成に必要な範囲においてのみ利用する。

  1. 本サービスの提供、維持及び運営（本人認証、データの保存及び表示、共有機能の提供並びに通知の送信を含む。）
  2. ユーザーの登録内容の確認及び所属ユニオンの管理者による利用承認
  3. ユーザーからの問合せ、不具合報告及び本方針第11条に定める請求への対応
  4. 利用規約に違反する行為その他の不正利用の防止及び調査
  5. 本サービスの改善及び新機能の開発

当団体は、取得した個人情報を広告の配信、販売その他前各号に掲げる目的以外の目的のために利用しない。

第5条（利用目的の変更）

当団体は、変更前の利用目的と関連性を有すると合理的に認められる範囲内においてのみ利用目的を変更するものとし、変更した場合には、変更後の利用目的を本サービス上で通知し、又は公表する。

第6条（第三者提供の制限）

当団体は、次の各号のいずれかに該当する場合を除き、あらかじめ本人の同意を得ることなく、個人データを第三者に提供しない。

  1. 法令に基づく場合
  2. 人の生命、身体又は財産の保護のために必要がある場合であって、本人の同意を得ることが困難であるとき
  3. 国の機関若しくは地方公共団体又はその委託を受けた者が法令の定める事務を遂行することに対して協力する必要がある場合であって、本人の同意を得ることにより当該事務の遂行に支障を及ぼすおそれがあるとき
  4. その他個人情報保護法第27条第1項各号に該当する場合

第7条（本サービス内における閲覧の範囲）

  1. ユーザーが登録した情報は、当該ユーザー本人のほか、当該ユーザーが共有機能により明示的に許可した他のユーザーに限り、許可された範囲で閲覧することができる。ユーザーは、共有の相手方及び範囲を自らの責任において設定するものとし、いつでもこれを解除することができる。
  2. 所属ユニオンの管理者は、利用承認のため、第3条第1号及び第2号に掲げる情報に限り閲覧することができる。
  3. 当団体は、障害対応、不正利用の調査、第11条に定める請求への対応又は法令に基づく場合その他必要がある場合に限り、必要最小限の範囲でユーザーの登録情報を確認することがある。

第8条（外部事業者の利用及び外国にある第三者）

  1. 当団体は、本サービスのデータの保存、認証及び通知の送信のため、Google LLC（アメリカ合衆国）が提供する Firebase その他のクラウドサービスを利用する。ユーザーの個人情報は、日本国外に所在するサーバーに保存される場合がある。
  2. 前項の事業者による個人情報の取扱いは、当該事業者のプライバシーポリシーその他の定めに従う。アメリカ合衆国における個人情報の保護に関する制度については、個人情報保護委員会のウェブサイトにおいて確認することができる。
  3. 当団体は、前各項に定めるもののほか、個人データの取扱いを外部に委託する場合には、委託先において個人データの安全管理が図られるよう、必要かつ適切な監督を行う。

第9条（安全管理措置）

当団体は、個人データの漏えい、滅失又は毀損の防止その他の個人データの安全管理のため、次の各号に掲げる措置を講ずる。

  1. 組織的安全管理措置：個人データの取扱いに関する責任者を定め、取扱状況を確認する体制を整備する。
  2. 人的安全管理措置：本サービスの運営に従事する者に対し、個人データの適正な取扱いを周知し、徹底する。
  3. 技術的安全管理措置：通信の暗号化を行うとともに、本人、共有を許可された者及び必要な管理者以外の者がデータにアクセスできないよう、アクセス権限を設定する。利用を停止されたアカウントによるデータへのアクセスは遮断する。
  4. 外的環境の把握：外国に所在するサーバーにデータを保存するにあたり、当該外国における個人情報の保護に関する制度を把握した上で安全管理措置を講ずる。

第10条（登録対象者の個人情報に関するユーザーの責任）

  1. ユーザーは、登録対象者の個人情報を本サービスに登録する場合、自らが適法かつ公正な手段により知り得た情報に限り登録するものとする。
  2. 登録対象者の個人情報の取得、管理、利用及び提供に関する一切の法的責任は、当該情報を登録したユーザーが負うものとし、当団体はこれを負わない。
  3. ユーザーは、登録対象者の個人情報を自己の活動及び人間関係の管理の目的にのみ利用するものとし、本人の同意なく不特定多数の者に公開し、又は拡散してはならない。
  4. 登録対象者から、当該登録対象者に関する情報の開示、訂正、利用停止又は削除の申出があった場合、当該情報を登録したユーザーは、速やかにこれに対応しなければならない。当団体は、必要に応じて当該対応を支援する。
  5. ユーザーが前各項の定めに違反したことにより、当団体又は第三者に損害が生じた場合、当該ユーザーはその損害を賠償する責任を負う。

第11条（保有個人データの開示等の請求）

  1. ユーザー本人は、当団体に対し、当該本人が識別される保有個人データの利用目的の通知、開示、内容の訂正、追加若しくは削除、利用の停止若しくは消去又は第三者への提供の停止（以下「開示等」という。）を請求することができる。
  2. 前項の請求は、第16条に定める窓口に対して行うものとする。当団体は、請求者が本人であることを確認した上で、法令の定めに従い、遅滞なく対応する。
  3. 当団体は、開示等の請求に係る手数料を徴収しない。
  4. 当団体は、法令に定める事由に該当する場合には、開示等の全部又は一部に応じないことがある。この場合、当団体は、その旨及びその理由を遅滞なく本人に通知する。
  5. 前各項の定めにかかわらず、ユーザーは、本サービスの画面上で自らの登録情報を確認し、訂正し、又は削除することができる。

第12条（保存期間及び削除）

  1. 当団体は、利用目的の達成に必要な期間に限り個人情報を保存し、利用する必要がなくなったときは、遅滞なく消去するよう努める。
  2. ユーザーが退会を申し出た場合、当団体は、法令により保存が義務付けられているものを除き、当該ユーザーのアカウント及び登録情報を速やかに削除する。

第13条（端末への情報の保存）

本サービスは、ログイン状態の維持及び通信が不安定な環境における動作のため、ユーザーの端末内にログイン情報及びデータの一時的な複製を保存する。ユーザーは、本サービスの設定又は端末の操作によりこれを消去することができる。

第14条（漏えい等の事案への対応）

当団体は、個人データの漏えい、滅失、毀損その他の事案が発生し、又は発生したおそれがあることを知った場合、速やかに事実関係を調査し、被害の拡大を防止するとともに、個人情報保護法の定めるところにより、個人情報保護委員会への報告及び本人への通知その他必要な措置を講ずる。

第15条（未成年者の利用）

未成年者が本サービスを利用する場合には、法定代理人の同意を得た上で利用するものとする。

第16条（運営者及び問合せ窓口）

本方針に関する問合せ、開示等の請求及び苦情の申出は、次の窓口において受け付ける。

名称PROMOTE
所在地・代表者本人の求めに応じて遅滞なく回答する。
受付窓口本サービス内「設定」→「バグ・要望」から送信するものとする。又は、所属ユニオンのリーダーを通じて申し出ることができる。

第17条（本方針の変更）

  1. 当団体は、法令の改正、本サービスの内容の変更その他の事情により、本方針を変更することがある。
  2. 本方針を変更した場合、当団体は、変更後の内容及びその効力発生日を本サービス上で通知する。重要な変更を行う場合、当団体は、変更後の本方針についてユーザーの同意を改めて取得するものとし、ユーザーは、当該同意をしない限り本サービスを利用することができない。
