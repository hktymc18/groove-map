2リーダーの役割

受付管理システムでは、人によって見える画面とできることが変わります。リーダーはオーナーがユニオンごとに指定します。

👑オーナー

全部の設定。ユニオン管理者・リーダーの指定、特別カード、ユニオン名の変更。

🛡ユニオン管理者

そのユニオンの責任者。名簿の編集・会計・受付管理者の任命・研修生の昇格。

🎫受付管理者

名簿の編集・イベント作成・会計・受付。

⭐リーダー（あなた）

名簿と集計を見る・研修生登録の担当を任命する・研修生を登録する。

🎓研修生登録の担当

研修生登録のページで、研修生の登録と受講の記録。

🙂メンバー

受付とイベントのタブだけ。自分の会員証。

3受付管理システム

開くのはこのURL。iPhone は Safari で開いて「共有 → ホーム画面に追加」すると、アプリのように使えます。

受付管理を開く ›

📋 名簿を見る

  1. 上の「名簿」タブ自分のユニオンのメンバーが並びます。リーダーは「閲覧のみ」です。
  2. タイトルで並べ替え・絞り込みタイトルを押すと高い順。タイトル: すべてで「RUBY 以上」などに絞れます。
  3. 会員証を渡す各行の会員証→QRで渡すを本人のスマホで読んでもらうか、URL を LINE で送ります。

横にスワイプ →

📊 集計を見る

  1. 上の「集計」タブ月ごとの開催数・平均の稼働数。
  2. 系列別の平均稼働数どの系列がどれだけ来ているか。
  3. メンバー別の出席●が出席。当月と「直近1ヶ月」の稼働率。NAVIGATOR の稼働率はこの数字を取り込みます。

横にスワイプ →

📅 イベントと受付

  1. 「イベント」タブ今月の予定。イベントを作るのは管理者です。
  2. 当日の受付「受付」タブでイベントを選んで受付を開始。来た人の会員証の QR を読むだけで出席になります。

横にスワイプ →

🎓 研修生登録の担当を任命する

  1. 「名簿」タブ → ⚙ 管理メニュー → 🎓 研修生登録の担当
  2. 担当にする人にチェック → 保存出てくるのは、同じユニオンでアカウントを持っている人です。
  3. URLをコピーして担当に送る研修生登録ページの URL です。
使い方ガイド：右上の🔰 使い方から、このガイドと、受付の練習モード（本番に記録されない）が開けます。

4会員証のしくみ

会員証は一人ひとり専用の URL。グレードとタイトルで、カードの見た目が変わります。

グレード（カードの色）

タイトル（RUBY・DIAMOND は専用デザイン）

  • タイトルの順番：BR → GOLD → LAPIS → RUBY → EMERALD → DIAMOND → BLUE DIAMOND → TEAM ELITE
  • BLUE DIAMOND・TEAM ELITE は、さらに特別なデザイン（オーナーが設定）。
  • 役職のバッジ（EXPERT・DIRECTOR など）も、カードに付けられます。
  • グレード・タイトル・バッジを変えるのは管理者。変えると本人の会員証にもそのまま反映されます（URL・QR は変わりません）。
会員証をなくした・スマホを変えた：同じ URL を開けばそのまま使えます。URL が分からない時は管理者に「会員証URL」を聞いてください。

5研修生登録

研修生の登録と、研修の受講記録をするページです。担当に任命された人とリーダーが使えます。

研修生登録を開く ›

はじめの1回：秘密保持の誓約

最初に開いた時だけ、秘密保持契約の内容を最後まで読んで、名前と住所を入れて同意します。

研修生を登録する

  1. ＋ 登録で名前・紹介者・UP ルビーを入れる番号は自動で決まります。
  2. 登録して会員証QRを表示
  3. 本人のスマホで QR を読んでもらう本人の「研修受講カード」が開きます。ホーム画面に追加してもらえば完了。

横にスワイプ →

研修のあと：受講を記録する

  1. 研修後入力で研修生を開く一覧から選ぶか、番号を入れて開く。📷 QRで本人の会員証を読んでも開けます。
  2. ✓ 受講済みにする受講した日とあなたの名前で記録されます。
  3. 必要に応じて📝 宿題（PG のあとの目標設定）・📝 面談シート（CO）・📅 会場受講を予約（DLR）。

横にスワイプ →

次の担当にバトンを渡す

研修生のページの下の🔗 次の担当に送るで、LINE にリンクを送れます。受け取った担当はタップするだけで開けるので、番号を聞く必要はありません。

開けるのは研修生登録の担当だけ。リンクには番号しか入っていません。

昇格（正規メンバーへ）

PG・PA・CO・BPC済み（DLR・EXP 以外）が受講済みで、面談シートを出したら「昇格待ち」になります。昇格は管理者が名簿から行います。会員証はそのまま、正規メンバーのカードに変わります。

6つながりマップ

「この設定をすると、どこに効くか」。組織を見るリーダー目線でまとめました。

🎫 名簿に人がいる・出席を付ける→ 集計の稼働率 → NAVIGATOR の MAP の稼働率付ける人：受付する人

QR で受付するだけ。NAVIGATOR では計算せず、受付の数字をそのまま取り込みます。

🎓 研修の受講済み（PG・DLR・PA・CO など）→ NAVIGATOR の研修生のステップ付ける人：研修生登録の担当・リーダー

MAP を開くと1日1回、受付の受講記録が研修生のステップに「進んだ」として入ります。

👥 名簿の紹介者→ NAVIGATOR の「名簿から追加」で MAP の置き場所入れる人：研修生を登録する人

紹介者が MAP にいれば、その人の下に置かれます。紹介者は正しく入れてください。

🔗 NAVIGATOR のアカウントと名簿の紐付け→ 受付で「無効」にすると NAVIGATOR も止まる・カードコレクションする人：ユニオン管理者（NAVIGATOR のアカウント管理）

やめた人のデータを守るため。紐付けると、受けた OL のカードも NAVIGATOR で見られます。

🎓 OL チェックアウト（会員証から）→ 本人の NAVIGATOR の ToDo・予定する人：OL を受けた本人

アウトラインのあと、A さんの QR を読んで感想・気づき・タスクを送ります。タスクが本人の NAVIGATOR に入ります。

📝 目標設定の宿題（会員証）→ NAVIGATOR の目標する人：研修生本人

会員証の「NAVIGATOR に引き継ぐ」で、答えた内容が目標に入ります。

👑 タイトル（名簿）→ 会員証のデザイン・NAVIGATOR の先行利用変える人：管理者／先行利用はオーナー

NAVIGATOR は RUBY 以上 → BR 以上の順に公開予定。名簿の📋 名前をコピーで対象の人を出します。

🎯 ATTACK LIST の進み具合→ NAVIGATOR のホームの人数付ける人：本人

「未着手・連絡中」と「CT予定」の人数が、NAVIGATOR に自動で出ます。「ATTACK LISTを見る」からすぐ開けます。

🙍 プロフィール（名前・ユニオン・UP ルビー）→ NAVIGATOR・ATTACK LIST・GOAL SETTING で共通変える人：本人

どれか1つで変えると全部に反映されます。個人情報の同意も1回で全部に。

🏷 ユニオン名→ 受付・NAVIGATOR・ATTACK LIST の全部変える人：オーナー

名前が変わる時はオーナーに。全部のアプリにまとめて反映されます。

7NAVIGATOR との連携

自分の MAP に、受付の名簿と稼働率を取り込みます。MAP の⟲ 受付連携から。

  1. ① 稼働を取り込むMAP の人と受付の名簿をつないで、直近1ヶ月の稼働率を入れます。名前が同じ人は自動でつながります。
  2. ② 名簿から追加受付の名簿にいて MAP にまだいない人を、紹介者の下に追加。受講済みの研修もステップに入ります。
  3. ③ 名前をそろえるMAP と名簿で字が違う人（高橋⇔髙橋 など）を、名簿の名前にそろえます。
ほかの地域のユニオンの人：その人のユニオンの受付管理者に、名簿で「MAP で連携するユニオン」にあなたのユニオンを選んでもらうと、つなげられます。
MAP で OUT にした人は、取り込みの対象外です（稼働率・研修・OL チェックアウト）。

8ATTACK LIST

これから声をかけたい人を、1人ずつカードにして管理するアプリです。メンバーに共有してもらうと、リーダーも見て一緒に作戦を立てられます。

ATTACK LIST を開く ›

📝 リストを作る

  1. 右下の＋で人を追加名前だけで保存できます。年齢・関係性・仕事・信用度（S〜D）・ニーズなど、分かるところから。
  2. カードを開いて進み具合を付ける未着手 → 連絡中 → CT予定 → CT済み → つながった → 体感済み → BPC済み／ユーザー。合わない人は NG。
  3. 「最有力」「有力」の目印一人暮らし・友だちが多そう・信用度などから、アプリが自動で付けます。

横にスワイプ →

📄 CDATA（個別の前に共有するデータ）

  1. カードのシート → CDATAリストに入っている内容は自動で入ります。入力は自動で保存。
  2. プレビュー → 📋 コピー文面のまま LINE に貼って送れます。

横にスワイプ →

👥 メンバーのリストを見る（リーダー）

  1. メンバーが共有コードを出すメンバーの⚙ 設定・共有 → 共有コードを発行（24時間有効）→ 送る文面をコピーであなたに送ってもらいます。
  2. あなたがコードを入れるあなたの⚙ 設定・共有 → 「共有コードを受け取った」に入れて受け取る。
  3. 右上の人のマーク → メンバーを選ぶ「閲覧中」の間は見るだけ（編集はできません）。← 自分のリストに戻るで戻ります。

横にスワイプ →

🏠 Family DATA

右上の家のマークから。家族の図・影響力の順番・キーパーソン・アプローチ作戦をまとめます。見せてもらったリーダーは、家族ごとに「U ラインからのアドバイス」を書けます。

OUT にする：メンバーのリストのOUTにするは、ユニオン管理者と、管理者が指定したリーダーだけに出ます。OUT にした人は ATTACK LIST・NAVIGATOR・GOAL SETTING にログインできなくなります（「元に戻す」で戻せます）。

9困ったとき

名簿に名前がない・名前が間違っている

名簿を直すのはユニオン管理者・受付管理者です。正しい名前と番号を伝えてください。

研修生が「研修後入力」の一覧に出ない

一覧に出るのは、自分が登録・受講済みにした人と、番号・リンク・QR で開いた人です。番号を入れて「開く」か、本人の会員証の QR を「📷 QR」で読んでください。前の担当に「🔗 次の担当に送る」で送ってもらうのが早いです。

研修生登録のページが「任命されていません」になる

リーダーか、ユニオン管理者に「研修生登録の担当」に任命してもらってください。

会員証のオンライン申請が「申請できません」になる

受付で記録済みの可能性があります。会員番号を受付担当に伝えて確認してもらってください。

稼働率が NAVIGATOR と合わない

NAVIGATOR は受付の「直近1ヶ月」の数字を取り込みます。受付連携で、その人が名簿とつながっているか確認してください。

パスワードを忘れた・ログインできない

NAVIGATOR のログイン画面でメールアドレスを入れて「パスワードを忘れた」を押すと、再設定のメールが届きます（アカウントは全部のアプリで同じなので、受付・研修生登録・ATTACK LIST もそのパスワードで入れます）。解決しない時は管理者へ。

📮 連絡先

困った時は、各ユニオンの管理者に連絡してください。管理者は受付管理の名簿→👥 管理者一覧で確認できます。
